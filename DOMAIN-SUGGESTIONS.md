# Sugerencias de dominio

Candidatos de estilo local `.mx` para el proyecto:

- `guiacibeles.mx`
- `cibelesroma.mx`
- `fuentecibelesroma.mx`
- `visitacibeles.mx`
- `cibelescdmx.mx`

En la búsqueda pública realizada para preparar el proyecto no aparecieron páginas ni registros indexados para estos nombres. La disponibilidad real sólo se confirma al momento de registro en un registrar acreditado por Registry .MX / NIC México, porque un dominio puede registrarse en cualquier momento y un dominio registrado puede no tener DNS o web activa.
